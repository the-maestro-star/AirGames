# Rock Paper Scissors Game (Camera-Based) ✊✋✌️

![Game Screenshot](assets\game-screenshot.png)

## 🖥️Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Flask (Python)  
- **Other Tools:** OpenCV / MediaPipe (for gesture recognition), Canvas API, Confetti.js  



## 🌟 Features

- Real-time hand gesture recognition (Rock/Paper/Scissors)
- Interactive countdown animation before each round
- Confetti celebration when you win 🎉
- Adjustable winning score (play to 10, 15, or 20 points)
- Simple controls: Play, Pause, Reset

## 🎮How to Play
1. Go To 🎮Games

2. Go To Rock Paper Scissors

3. Allow Camera Access When Prompted

4. Choose Target Score (10,15,20)

5. Wait for Countdown(Rock, Paper, Scissors, Shoot)

6. Show Your Gesture Clearly
- ✊ Rock (closed fist)
- ✋ Paper (open palm)
- ✌️ Scissors (V-sign)

7. The Computer Will Respond Automatically

8. First To Reach Target Score Wins
![Game Screenshot](assets\game-screenshot2.png)

## 🚀Tips for Best Performance
- Use in a well-lit room (but avoid direct bright light)

- Keep your hand centered in frame and upright

- Make clear, deliberate gestures

## 🔀 Resetting or Pausing
- Click Reset to start a new game and choose a new score.

- You can also Pause and Resume during gameplay.

- If you win, enjoy a 🎉 confetti blast to celebrate!
