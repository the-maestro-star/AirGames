About the Project

Rock-Paper-Scissors AI Game is an interactive web application that lets users play the classic hand game against a computer using real-time gesture recognition via webcam. Built with modern web technologies and powered by machine learning, this project captures your hand gestures using your device's camera, analyzes them, and instantly pits them against the computer's move.

Key features include:

  • Camera-Based Gesture Detection - Detects your hand signs using live video input.
  • AI-Powered Gameplay - Uses a trained model to recognize rock, paper, or scissors.
  • Animated Countdown - Builds excitement with a rock, paper, scissors, shoot before each round.
  • Visual Feedback - Shows your hand gesture as an image overlay for clarity.
  • Confetti Celebrations - Win a round? Celebrate with colorful confetti!
  • Custom Round Limits - Choose your winning score: 10, 15, or 20

This project blends computer vision with intuitive user interaction and was built to explore the intersection of machine learning, game design, and web development.
